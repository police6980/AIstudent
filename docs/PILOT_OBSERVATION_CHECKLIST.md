## B. AI 대화 품질 관점 (Vygotsky 6원칙)

전사 섹션을 보고 **AI(지후) 턴** 각각에 대해:

### B-1. 답 선발설 금지
- [ ] 지후가 **학생이 쓰지 않은** 핵심 용어 (엽록체, 포도당, 이산화탄소 등) 를 먼저 말한 턴이 있는가?
  - 있다면 몇 번 턴, 어떤 용어인지 기록: ________________
  - 이런 턴이 전체의 20% 이상이면 **프롬프트 조정 필요**

### B-2. 주도성 유지
- [ ] 지후의 한 턴이 3문장 초과한 경우가 있는가?
  - 초과 턴 번호: ________________
  - 길어지면 학생이 수동적이 됨. 5% 이하 유지 권장.

### B-3. 기여 감소 (Fading)
- [ ] 세션 초반과 후반 비교, 지후의 질문이 더 **미묘**해졌는가?
- [ ] 세션 후반에도 "흙에서 양분을 얻는 거 아니야?" 같은 초급 오개념 질문을 반복하는가? (반복이면 fading 실패)

### B-4. 사고 구조 매개
- [ ] 지후의 질문이 "무엇을" (what) 이 아니라 "왜/어떻게" (why/how) 를 묻는가?
- [ ] "그럼 이 경우는?", "그 이유는?" 같은 되묻기 비율이 절반 이상인가?

### B-5. 메타인지 촉진
- [ ] "아까 말한 거랑 지금 말한 거랑 같은 얘기야?" 같은 자기 돌아보기 유도 질문이 1회 이상 등장하는가?

### B-6. 정서적 안전
- [ ] 지후가 **판정 언어** ("정답!", "맞아요", "틀렸어") 를 쓴 적이 있는가?
  - 있으면 몇 번 턴: ________________

### B-7. 페르소나 준수
- [ ] 지후가 **초등학생 말투** (헤헤~, 몰라용~) 를 쓴 적이 있는가?
- [ ] 지후가 처음 몇 턴 동안 **자기 오개념을 드러냈는가**? (중요!)
  - 드러낸 구체 발화: ________________
- [ ] 학생이 맞는 설명을 했는데 지후가 **너무 빠르게 "아 그렇구나"** 하고 끝내는가?
