## 1. 이론적 배경 — Ausubel의 유의미 학습

Joseph D. Novak(1972)은 Cornell 대학에서 어린이들의 개념 변화를 추적하는 도구로 개념도를 개발했다.
이론적 뿌리는 Ausubel의 **유의미 학습 이론(Meaningful Learning / Assimilation Theory)**:

- 새로운 지식은 학습자가 **이미 가진 관련 개념(선행 조직자)** 에 **연결**될 때 유의미해진다.
- 연결되지 않으면 암기(rote learning)가 되어 금방 잊혀진다.
- 유의미 학습의 **필요 조건**:
  1. 학습자에게 관련 선행 개념이 존재
  2. 학습 자료가 잠재적으로 유의미한 구조를 가짐
  3. 학습자가 유의미하게 학습하려는 **의지**

개념도는 이 "연결 구조"를 **시각화**하여 학습자와 교사가 함께 볼 수 있게 한 도구다.

## 2. 개념도의 5가지 핵심 요소

### (1) 개념(Concepts)
- **정의**: 대상·사건·속성에 대한 **규칙성**을 표현하는 단어 또는 라벨.
- **형태**: 보통 명사구. 동그라미 또는 사각형 안에 작성.
- 예: `광합성`, `빛`, `엽록체`, `포도당`.

### (2) 명제(Propositions)
- **정의**: 두 개념을 **연결어(linking words)** 로 이은 **의미 단위**.
- **중요성**: 개념도의 **기본 의미 단위**. 개념이 얼마나 많으냐보다 **명제가 얼마나 많고 정확하냐** 가 본질.
- 예: `광합성 —[의 조건은]→ 빛`, `엽록체 —[에서 일어난다]→ 광합성`

### (3) 위계 구조(Hierarchical Structure)
- **정의**: 가장 **포괄적·일반적** 개념이 위, 점차 **구체적** 개념이 아래.
- **Ausubel 기반**: 새 지식은 더 일반적인 개념에 **포섭(subsumed)** 된다.
- 잘 만든 개념도는 위에서 아래로 읽었을 때 **점점 구체화** 되는 구조.
- 예: `광합성` (상위) → `조건 / 산물 / 장소` (중간) → `빛, 물, 이산화탄소 / 포도당, 산소 / 엽록체` (하위) → 구체 예시.

### (4) 교차연결(Cross-links) ⭐
- **정의**: 개념도의 **서로 다른 가지(branches)** 에 있는 개념 간 연결.
- **Novak의 핵심 통찰**: 교차연결은 학습자의 **창의적·통합적 사고** 를 보여주는 가장 중요한 지표.
- 서로 다른 영역을 의미 있게 연결할 수 있다는 것은 **깊은 이해** 의 증거다.
- 예: 위계에서 "조건" 가지의 `빛` 과 "장소" 가지의 `엽록소` 를 연결 —
  `엽록소 —[가 흡수하는]→ 빛` 은 서로 다른 분류 축을 통합.

### (5) 구체 예시(Specific Examples)
- **정의**: 개념의 **구체적 사례·사건·객체**.
- 위계의 가장 하단에 위치.
- 예시가 있다는 것은 개념이 **추상어**가 아니라 **경험에 닿아 있다**는 증거.
- 예: `포도당` 의 예시 = `설탕은 식물이 만든 포도당의 변형`.

## 3. Novak & Gowin(1984)의 전통적 채점 기준

연구에서 개념도 품질을 정량화할 때 사용하는 **기본 가중치**:

| 요소 | 점수 | 설명 |
|------|------|------|
| 유효한 명제(Valid proposition) | +1 | 개념-연결어-개념이 의미상 올바른 경우 |
| 위계 수준(Hierarchy level) | +5 | 위계의 각 수준마다 |
| 교차연결(Cross-link) | +10 | 유효한 경우 (유효하지 않으면 +2) |
| 구체 예시(Example) | +1 | 개념당 예시 |

**시사점**: 교차연결은 명제 10개와 같은 비중 — 창의적 통합이 그만큼 귀하다.

## 4. 좋은 개념도의 5가지 속성 (Novak, 1998)

연구자가 개념도 품질을 평가할 때 확인할 다섯 축:

1. **명료성(Clarity)**: 라벨이 분명하고 연결어가 의미를 정확히 전달하는가.
2. **정확성(Correctness)**: 명제들이 과학적으로 옳은가.
3. **포괄성(Comprehensiveness)**: 단원의 핵심 개념들을 망라하는가.
4. **교차연결(Cross-linking)**: 가지 사이의 통합적 연결이 있는가.
5. **예시(Examples)**: 구체 사례로 개념이 뒷받침되는가.

## 5. 개념 변화 추적 — 전/후 개념도 비교

개념도는 **학습 전과 후** 를 비교할 때 특히 강력하다.

### 변화의 6가지 유형
1. **추가(Addition)**: 새로운 개념이 들어옴.
2. **정교화(Elaboration)**: 기존 개념에 하위 개념·예시가 추가됨.
3. **재구조화(Restructuring)**: 위계 구조 자체가 바뀜.
4. **교차연결 생성(Integration)**: 전엔 없던 가지 간 연결이 생김 — **가장 중요**.
5. **오개념 교정(Correction)**: 부정확하던 명제가 정확해짐.
6. **오개념 지속(Persistence)**: 교정되지 않은 오개념 존재.
